# AI Chatbot

## Introduction
The AI Chatbot is a web-based application that lets users chat with an
intelligent assistant. Users type a question, and the chatbot replies with
a helpful answer in a simple chat window. It can be used for answering common
questions, such as college information, FAQs, or general help.

## Features
- Simple and clean chat interface
- Users can type messages and get instant replies
- Chat history shown in the conversation window
- Predefined answers for common questions (FAQs)
- Works on both desktop and mobile screens
- Clear chat button to start a new conversation

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub (version control and hosting)
- GitHub Pages (publishing the documentation)

## Installation
1. Download the project.
2. Open the project folder.
3. Open index.html in a browser.

## Usage
1. Open the chatbot page in your browser.
2. Type your question in the message box.
3. Click the Send button.
4. Read the chatbot's reply in the chat window.
5. Click Clear Chat to start again.
